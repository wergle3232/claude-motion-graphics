# Example: Logo sting (MORF, 16:9, 4 s)

**The job:** An intro or an outro: the logo built in a few hits.

**A sentence to start one like it:** "Make a 3 to 4-second logo sting from my logo."

It was made over a short conversation, not from that one sentence: a first version, then a few notes. The sentence is a good way to start.

**What is on screen**

- The mark's square becomes a circle that becomes the O of the wordmark.
- The letters slam in.
- A last hit, then hold on the logo.

**Library moves in it:** built in the piece; the logo is rebuilt from live shapes so it can morph.

**Files:** `source/index.html` (the canvas and layout), `source/shared/piece.css` (the look), `source/shared/piece.js` (the beats and motion).

**Sound:** Sound effects from HyperFrames' bundled set (copy them in, see [the examples README](../README.md)): click.mp3, impact-bass-1.mp3, key-press.mp3, ping.mp3, whoosh-short.mp3.
