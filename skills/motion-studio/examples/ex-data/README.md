# Example: Data (MORF, 16:9, 7.5 s)

**The job:** A stat for a post or a video: a number, a chart and a ring, docking into a dashboard.

**A sentence to start one like it:** "Make three made-up numbers move for a dashboard: one counts up, one is a bar chart that builds, one is a ring that fills. End with all three together."

It was made over a short conversation, not from that one sentence: a first version, then a few notes. The sentence is a good way to start.

**What is on screen**

- A number counts up and lands hard.
- A bar chart builds.
- A ring fills.
- All three dock into one dashboard and hold.

**Library moves in it:** built in the piece; every number is made up and labelled as an example.

**Files:** `source/index.html` (the canvas and layout), `source/shared/piece.css` (the look), `source/shared/piece.js` (the beats and motion).

**Sound:** Sound effects from HyperFrames' bundled set (copy them in, see [the examples README](../README.md)): click-soft.mp3, click.mp3, impact-bass-1.mp3, key-press.mp3, ping.mp3, pop.mp3, whoosh-short.mp3.
