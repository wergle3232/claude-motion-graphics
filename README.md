# Trial pieces

Pieces made while building the plugin, to show what it produces and to find its problems. This branch is never to be made public. Each folder has the brief, the brand file it was made from, the renders, the contact sheet and phone test the critique read, and notes with the scores.

- `kiln-promo/`: a 15-second product promo for a made-up booking app, in 9:16, 4:5 and 16:9 from one timeline. One storyboard round (`storyboard-1.png`), three critique rounds. Effects only, no music.
- `northlight-overlay/`: transparent overlays for a made-up podcast's talking-head video, in 16:9 and 9:16, shown over a stand-in.

Not made yet: the explainer and the carousel trials. They will be made together with the owner, using the installed plugin.
